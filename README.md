# SplitSense（歧見預判）

> 以文字特徵與標註歷史預測標註分歧：英文與繁體中文複核排序之比較研究

在一筆資料只取得部分標註時，預測完整標註結果是否會出現分歧，讓固定的人工複核預算優先落在較可能分歧的項目上。

本專案是機器學習實作課程的期末專題，也是 Label Suite 的技術調研與離線原型；**不**取代標註者、**不**裁定哪一個標籤正確，也不把分歧直接等同於標註錯誤。

## 範圍

| 層級 | 必要性 | 內容 |
| --- | --- | --- |
| 英文真實資料 | 必做 | TID-8 中保留 `item_id`、`annotator_id` 與個別標籤的子資料集 |
| 繁體中文 pilot | 必做 | 150 至 300 筆文字，每筆至少 3 位標註者獨立標註 |
| 隨機與規則基準 | 必做 | 隨機排序、可見標籤熵、票數差距 |
| 傳統分類模型 | 必做 | Logistic Regression、Gradient Boosting |
| 多語 Embedding | 必做 | `BAAI/bge-m3` 本機產生，英文與繁中共用 |
| GraphSAGE | 選做 | item–annotator 異質二分圖 |

## 狀態

設計階段：研究規格撰寫中，尚無實驗程式碼。

## 資料

本 repo 不收錄任何資料檔。英文資料依原始授權自行下載；繁中 pilot 的原始文字與個別 annotation 不公開。
